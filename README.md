# AUTOS

AUTOS is a browser-based, physics-first vehicle sim. The source is available for noncommercial use.

**Play:** https://ledogen.github.io/Autos/

This is the official build, maintained by ledogen. Questions or interest: ledogen@gmail.com

## Run locally

```
npm install
npm run dev     # http://localhost:8000
npm test        # regression gates
```
