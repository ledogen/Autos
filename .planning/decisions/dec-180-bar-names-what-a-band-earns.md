# DEC-180: The rank bar names what each band earns, not a letter

**Ruling.** "what each line earns (full tip, deed 1, deed ½, the item), no letters". Strip bands read full tip / deed 1 / deed ½, the tile beside it names the live earning (TIP+DEED, DEED, ½ DEED), and its label is "Earns:". Letters stay inside the code (item gates, deeds).

**Why.** A letter on a calm type would contradict the card's own axis (e.g. "69%+ intact"); words say what the player gets.

**Replaces.** S/A/B/C/D lettering of the bar and tile. The result cards keep their letters (option A was not taken).

**Source.** Owner, deep dive QUAL-36-mission-grading, submitted 2026-11-14. Owner's words.
