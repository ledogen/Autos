# DEC-094: Lane branches commit work in progress at every step

**Ruling.** On a lane or feature branch, commit work in progress at every working step; on resume, uncommitted changes are yours to commit, never discard. Main gets commits only at a task boundary or when asked.

**Why.** An uncommitted tree is lost work after a crash ("most important").

**Replaces.** Nothing.
