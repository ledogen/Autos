# DEC-093: Work in the session's worktree; every handoff names worktree, branch and port

**Ruling.** After a context break, edit in the worktree the window names, never feature work on main; every handoff names the worktree path, branch and port.

**Why.** The wrong tree is how work gets lost or lands unreviewed.

**Replaces.** Nothing.
