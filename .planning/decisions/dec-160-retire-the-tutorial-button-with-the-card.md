# DEC-160: The menu's tutorial button and the tutorial's no-save rule retire with the card

**Ruling.** "retire both with the card": once the intro's card offers the tutorial, the main menu's "tutorial" button goes, and the tutorial saves as part of the run.

**Why.** The card duplicates the button, and a tutorial that flows into free will is the start of the run, so not saving it would lose the run.

**Replaces.** The 2026-11-08 menu split (FEAT-184: a "tutorial" button, never touching the career save), at the card's landing.

**Source.** FEAT-184 tutorial-flow dive, answer "menu-button" (owner, 2026-11-14). Owner's words.
