# DEC-082: Vehicles are modelled from an 8-photo reference board

**Ruling.** A vehicle is modelled against an 8-photo reference board, primitive first, comparing named features every pass; never from memory.

**Why.** Memory gets proportions wrong; named features make each pass checkable.

**Replaces.** Nothing.
