# DEC-490: The stick dead zone is 0 to 20 % in 2 % steps, default 10 %

**Ruling.** "Stick dead zone should be increments of 2% minimum 0% maximum 20% default 10%". The settings row offers 0, 2, 4 … 20 %, and the default is 10 % (the debug slider matches).

**Why.** The row offered 4 / 8 / 12 / 16 % with 8 % the default.

**Replaces.** The 4 / 8 / 12 / 16 % options and the 8 % default.
