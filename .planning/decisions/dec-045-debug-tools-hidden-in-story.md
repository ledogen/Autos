# DEC-045: In the alpha, debug and teleport tools sit behind a cheat or debug mode

**Ruling.** The alpha hides story mode's debug tooling and teleports behind a cheat or debug mode rather than deleting the path.

**Why.** Testing a run still needs the tools; a player should not see them.

**Replaces.** Settled by FEAT-43 (alpha): DESIGN.md's "Debug tooling is locked out" in story mode.
