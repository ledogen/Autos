# DEC-126: A later presentation ruling beats an invariant's older wording

**Ruling.** A later owner ruling on what a card or HUD shows beats an invariant's older wording about it, as long as the invariant's purpose (par never shown, pay never reading the letter) holds.

**Why.** An invariant protects a purpose; the exact card wording it once described can move.

**Replaces.** Nothing.

**Source.** Axiom AX-5, deep dive INFRA-10-conflicts, 2026-11-13; the owner pressed approve. Agent wording, owner approved 2026-11-13.
