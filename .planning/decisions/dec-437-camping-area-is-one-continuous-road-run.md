# DEC-437: A camping area is one continuous piece of road, with an average size and variation

**Ruling.** "A single camping region often has multiple breaks due to the way their circle overlaps with the roads. Let's make it so each camping area is a continuous piece of road. I like how it can absorb intersections. Since it's not a fixed circle anymore, we should aim to have an average camping area size But build in variation on the size."

**Why.** A circle laid over a road network breaks into several pieces; a camping area should read as one place.

**Replaces.** Replaces the fixed-circle definition of a camping area. The size number is open (FEAT-299).
