# DEC-047: World knobs never go steeper than Classic; the hard grade cap and cTurn never move

**Ruling.** World knobs (terrain, props, road climbs) are set at run start and carried in the world code; nothing steeper than Classic is offered, and the hard grade cap and cTurn never move.

**Why.** "If it got much steeper than classic it would be quite deadly."

**Replaces.** Nothing.
