# DEC-421: Larry yellow, haul purple; purple allowed for a mission type

**Ruling.** "I think purple is permissible to use as a designator of a specific mission type. I prefer Larry Yellow and haul to be purple."

**Why.** Larry (papers) and haul were both white on the map; each mission type gets its own colour (DEC-131, DEC-413). The palette had no purple, so the ruling opens one for a mission type.

**Replaces.** Nothing superseded: no standing record assigned haul or Larry a colour (white was a code comment of 2026-11-13). Extends DEC-413 ("firewood purple") to the whole haul family. Colours chosen by the lane: yellow = `--key` #ffcf3c, purple = new token `--haul` #9b5fd1.

**Source.** Owner, in chat, 2026-11-18.
