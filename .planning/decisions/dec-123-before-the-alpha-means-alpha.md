# DEC-123: An owner's "before the alpha" puts a ticket in the alpha

**Ruling.** An owner ruling that a ticket is built before the alpha puts it in the alpha; the cut table is updated to list it.

**Why.** The cut table and the owner's own "before the alpha" must not disagree.

**Replaces.** "A ticket no table lists is later" (MILESTONES.md § Release cuts) for such tickets.

**Source.** Axiom AX-2, deep dive INFRA-10-conflicts, 2026-11-13; the owner pressed approve. Agent wording, owner approved 2026-11-13.
