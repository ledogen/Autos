# DEC-026: Rising costs are what push a run along; the storm is not planned

**Ruling.** Prices scale with the clock only, and that cost escalation is what pushes a run forward. The spreading "storm" front is not built and not planned.

**Why.** A treadmill the player can see in prices needs no second pressure system.
