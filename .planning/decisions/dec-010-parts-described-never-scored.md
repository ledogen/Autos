# DEC-010: Parts are described, never scored

**Ruling.** No number on a part, ever: an LSD changes what the truck does when you get greedy mid-corner, it doesn't grant +5 handling. Wear is a state, not a score — the service screen shows a part's condition as a percentage.

**Why.** Power mods on an open-diff RWD truck are a cursed item nobody had to author, which only works because nothing is hidden behind a stat.

**Replaces.** Nothing; the condition percentage (owner, 2026-10-22) clarified it.
