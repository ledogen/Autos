# DEC-027: Offers are seeded, the same for every vehicle; the truck only changes the verdict

**Ruling.** Offers stay seed-determined for every vehicle; the configuration only changes the load verdict (fits / warning / overload), and an overload is accepted at your own risk.

**Why.** A board that changed with the truck would read the build and leak a power curve into the world (SM-INV-12).

**Replaces.** Nothing.
