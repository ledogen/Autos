# DEC-042: An alpha run ends by winning, dying or giving up, then shows a summary

**Ruling.** An alpha run ends three ways — the expedition camp is beaten, the player dies, or the player gives up from the pause menu — and each ends on a run summary.

**Why.** A demo needs a real ending, and giving up is a choice rather than a fail state (SM-INV-1).

**Replaces.** Nothing.

**Source.** DESIGN.md 2026-10-23 pass; FEAT-146. Agent wording.
