# DEC-007: Every run starts in a randomized jalopy and can win

**Ruling.** Every run starts in a randomized jalopy, and every run is technically capable of beating the game. No meta power curve makes early runs uncompletable or late runs comfortable.

**Why.** The bad car forces the player to re-read the truck at minute one and makes a mid-run part find land as an event.

**Replaces.** Nothing.
