# DEC-303: The start arrow lies flat on the road, like a painted arrow

**Ruling.** "lay it flat over the road, like a painted arrow (recommended)". As the card put it: lay the arrow flat, hovering over the road like a painted road arrow pointing down the route; it reads from any direction.

**Why.** The upright start board (DEC-287, DEC-297) is a plate lying along the road, so a player standing on the road facing the wrong way met it edge-on, as a sliver.

**Replaces.** Only the arrow's posture: DEC-287's and DEC-297's board stood upright 2 m above the road. Position (10 m behind the start), vanish rule (START_GONE_M) and tutorial legs are unchanged, so neither record is superseded (DEC-297's "stands" is placement wording, not posture).

**Source.** Owner, card feat215-start-arrow-2, 2026-11-16. Owner's words, no note.
