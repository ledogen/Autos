# DEC-132: The map is an 80 % window with a nearest-first list and a custom waypoint

**Ruling.** The map takes about 80 % of the screen with the live game behind, and a list on the right swaps between Missions and Shopping with the bumpers, both sorted nearest first. Opening always centres on the truck and tracks it, B from a list starts panning from there, and the player can set a custom GPS waypoint.

**Why.** "build it like that" — the owner approved the control scheme on card feat211-controls.

**Replaces.** Nothing.

**Source.** FEAT-211 § Decisions (owner, 2026-11-13), including "one feature request. add a custom gps waypoint function. y on pad seems appropriate or maybe we can just use a/enter." The ticket's wording of the ruling.
