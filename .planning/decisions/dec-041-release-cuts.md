# DEC-041: The alpha is one region, polished; release is set only by the cut tables

**Ruling.** Alpha is one region (a 2500 m circle) as a polished demo; beta is 3–5 regions plus shortcuts, dirt roads and spirits. A ticket's release is set only by the `## Release cuts` tables in MILESTONES.md; nothing is deleted.

**Why.** One place decides scope, so a ticket can't quietly promote itself into the alpha.

**Replaces.** Nothing.
