# DEC-058: There is no default seed

**Ruling.** A player hits Random or types a seed; every world the player did not pick is random too (free roam, the world behind the menu, `?nomenu=1`). Only `?seed=` pins one, and seed 6 is a test seed, never "the world".

**Why.** Players almost never see seed 6, so results on it don't describe the game.

**Replaces.** Nothing.
