# DEC-129: The toolbox and the roof rack each add 4 inventory slots; visual mods ship before the alpha

**Ruling.** The toolbox and the roof rack each add 4 inventory slots. The visual mods are built before the alpha: the light bar is the older four-reflector incandescent style, and the toolbox sits right behind the cab.

**Why.** "4x more inventory slots means +4 slots"

**Replaces.** Nothing.
