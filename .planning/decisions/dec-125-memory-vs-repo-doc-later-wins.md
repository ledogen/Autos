# DEC-125: Between a memory note and a repo doc, the later-dated one wins

**Ruling.** When an agent memory note and a repo doc disagree, the later-dated one wins and the loser is corrected; an owner quote beats an agent's summary of the same date.

**Why.** Memory notes and repo docs drift apart; the date is the only fair tie-break, and the owner's own sentence outranks a summary of it.

**Replaces.** Nothing.

**Source.** Axiom AX-4, deep dive INFRA-10-conflicts, 2026-11-13; the owner pressed approve. Agent wording, owner approved 2026-11-13.
