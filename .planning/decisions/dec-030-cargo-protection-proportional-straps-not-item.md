# DEC-030: Straps are not an item

**Ruling.** Loose-load protection is built into the job (a strapped load costs the clean-up time), not bought as a ratchet-strap item.

**Why.** An item every haul needs is a tax, not a choice.

**Replaces.** FEAT-110 ratchet straps as an item (cancelled 2026-10-14).
