# DEC-158: A later run's tutorial ends by loading the run's random world

**Ruling.** "load the random world at the end": a later run that plays the tutorial on the tutorial seed returns to its own random world when the tutorial ends, outside that world's burger joint.

**Why.** The run keeps the world it was rolled; the tutorial seed is only the tutorial's.

**Replaces.** Nothing (the recommendation, to stay on the tutorial seed, was declined).

**Source.** FEAT-184 tutorial-flow dive, answer "tutorial-world" (owner, 2026-11-14). Owner's words.
