# DEC-062: Fewest buttons on menus; no hidden gestures

**Ruling.** Menus use the fewest controller buttons: the side menu is B-hold and the D-pad is spent on actions (down pick-up, right reset, left set spawn). No hidden gestures such as double-presses as mode switches — a natural signature or a settings toggle instead.

**Why.** Hidden gestures are "cheesy" and undiscoverable.

**Replaces.** Nothing.

**Source.** memory feedback_controller_button_budget (owner, 2026-11-03) and feedback_no_hidden_gestures. Date from the memory note. Agent wording.
