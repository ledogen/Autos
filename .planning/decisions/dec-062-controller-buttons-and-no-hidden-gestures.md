# DEC-062: Fewest buttons on menus; no hidden gestures

**Ruling.** Menus use the fewest controller buttons; on the pad the hold-B menu carries recovery, tow, inventory and the like. No hidden gestures such as double-presses as mode switches: a natural signature or a settings toggle instead.

**Why.** Hidden gestures are "cheesy" and undiscoverable.

**Replaces.** Nothing.

**Source.** memory feedback_controller_button_budget (owner, 2026-11-03) and feedback_no_hidden_gestures. Date from the memory note. Owner, 2026-11-13: "we have the hold-b menu on pad for recovery, tow, inventory, etc. otherwise i agree with the philosophy". Agent wording, owner approved 2026-11-13.
