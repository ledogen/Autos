# DEC-122: A later owner ruling beats an earlier one, wherever it is written

**Ruling.** When two owner rulings disagree, the later-dated one wins, whatever file holds it; the ticket rule applies only when the dates can't be told apart.

**Why.** The open-alpha-ticket rule assumed the alpha ticket held the newer ruling; where a newer ruling sits elsewhere, the date decides.

**Replaces.** The open-alpha-ticket rule as the first test (owner, 2026-11-13, earlier the same day).

**Source.** Axiom AX-1, deep dive INFRA-10-conflicts, 2026-11-13; the owner pressed approve. Agent wording, owner approved 2026-11-13.
