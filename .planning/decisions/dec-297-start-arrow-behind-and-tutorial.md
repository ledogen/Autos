# DEC-297: The start arrow stands 10 m behind the start; tutorial legs get it too

**Ruling.** "it should stand 10 opposite the gps direction along the road. The whole purpose of this arrow is to remind a player who's facing the wrong way which way they're supposed to go So if it's 10 meters along the route a player facing the wrong way never sees it. Flip it so it's behind the start point. That way a player facing the wrong way always sees it. A player facing the correct way sees the chevrons. Also, tutorial legs should get the start arrow as well."

**Why.** The owner's look at the built start arrow (DEC-287): 10 m ahead, a player facing backwards never saw it.

**Replaces.** Refines DEC-287's placement (10 m ahead of the start becomes 10 m behind it, still pointing the way the route goes) and its coverage (tutorial legs included). DEC-287 stays standing: the 20 m dismiss rule and the alerts are unchanged.

**Source.** Owner, card feat215-start-arrow-look, 2026-11-15. Owner's words.
