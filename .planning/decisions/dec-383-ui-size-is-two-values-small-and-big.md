# DEC-383: UI size has exactly two values: small (today) and big (a TV)
**Ruling.** "We need a UI scale option. Playing this on a TV, the text is way too small to read. It's about perfect on my 15 inch MacBook And on my 1440p 27 inch monitor. I'm actually a fan of the way the new Monster Hunter game has only two options for UI scale, so let's do the same. The current setting can be called small and the TV mode can be called big."
**Why.** Small is the size the owner already calls right on a laptop and a 27 inch monitor. Two steps, no slider.
**Replaces.** Nothing. The 12 px font floor and the type scale of UI-STYLE.md describe Small; Big multiplies them by one factor.
